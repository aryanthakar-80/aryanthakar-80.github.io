# Aryan Thakar - Engineering Portfolio

This repository hosts my engineering portfolio, focused on embedded systems, robotics, firmware, control systems, and hardware-oriented product development.

I'm an embedded systems engineer with a B.Tech in Electronics & Instrumentation Engineering from Nirma University. I'm currently an Electronics and Embedded Systems Intern at Articulus Surgical, where I develop C firmware for STM32 and TI platforms, bring up prototype PCBs, and debug hardware and firmware issues.

My projects span embedded systems, robotics, and control. I've built a K210 vision expansion board for STEM robotics kits, developed an underwater robot controller, and worked on sensor fusion for real-time localisation. I enjoy tracing a problem from what the firmware reports to what I can measure on the board. 

The portfolio highlights my internships, projects, skills, education, achievements, resume, and contact information.

## Focus Areas

- Robotics control, telemetry, and sensor integration
- Communication protocols including CAN, UART, SPI, I2C, I2S, and RS485
- Computer vision and AI-enabled embedded hardware
- Control systems, localisation, and sensor fusion
